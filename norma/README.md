# נורמה / NORMA — אתר המותג

אתר שיווק למוצר בקרת עלויות הרכש בבנייה. **מותג נפרד מ-shellygroup.co.il.**

מקור התוכן: `SPEC_procurement.md` (מפרט מערכת הרכש, Base44 app `6831d279a324b0b9eda7a0f4`).

---

## הפרדה מהאתר הקיים

הכל תחת `norma/` בלבד. אפס תלות דו-כיוונית:

| | האתר הקיים (שורש) | נורמה (`norma/`) |
|---|---|---|
| CSS | `assets/pages.css` + inline ב-`index.html` | `norma/assets/brand.css` |
| JS | `assets/lead.js`, `assets/a11y.js` | `norma/assets/app.js` |
| טוקנים | `--green #5f9c36`, `--wood`, בז׳ חם | `--datum #0e7a6e`, `--alarm #cf5227`, נייר/דיו |
| פונטים | Karantina · Frank Ruhl · Assistant | Heebo · Assistant · IBM Plex Mono |
| נכסים | `assets/` בשורש | `norma/assets/` |
| דאטה | Base44 app `6a2ff9d8…` | — |

הבדיקה: מחיקת `norma/` לא נוגעת באתר הקיים, ומחיקת כל השורש חוץ מ-`norma/` משאירה אתר שעובד.

**האתר הקיים לא נגע.** השינוי היחיד מחוץ ל-`norma/` הוא `Disallow: /norma/` ב-`robots.txt` בשורש,
כדי שגוגל לא יאנדקס מותג אחר תחת הדומיין של שלי גרופ. גם לדף עצמו יש `noindex`.

## שפה עיצובית

הרעיון: **המוצר הוא השוואה אחת** — נורמה מול בפועל. הפלטה מקודדת בדיוק את זה.

- `--datum` (טורקיז עמוק) = הנורמה, מה שהיה אמור להיות.
- `--alarm` (חלודה) = החריגה, מה שהיה בפועל.
- `--gold` = מסומן, ממתין לאימות מול מסמך.

מספרים הם המוצר, ולכן הם מקבלים טיפוגרפיה משלהם: `.num` = IBM Plex Mono,
`tabular-nums`, ו-`direction:ltr; unicode-bidi:isolate` כדי שמספרים ומטבע לא יתהפכו בתוך RTL.

מוטיב חוזר: סרגל מדידה (`.tick`) כמפריד בין סקשנים.

## מה חי בעמוד

- **גרף hero** — נורמה מול בפועל, מתמלא בגלילה.
- **מחשבון נורמות** (`#calc`) — בחירת פריט טוענת את מחיר הספר שלו, סליידר עובי,
  שטח מה-SOV וכמות שנרכשה בפועל. מחזיר ₪/מ״ר, אומדן לפרויקט, ופסק דין על הפחת.
  זה הליבה של המסמך בצורה שאפשר לגעת בה.

## פיצול לרפו/דומיין נפרד

1. `git subtree split --prefix=norma -b norma-only`
2. לדחוף את הענף לרפו חדש.
3. שם: `CNAME` עם הדומיין החדש + `.nojekyll`.
4. כאן: למחוק את `norma/` ואת שורת ה-`Disallow` מ-`robots.txt`.
5. להסיר את `<meta name="robots" content="noindex">` ואת `.sketchbar` מהדף.

הנתיבים בעמוד יחסיים (`assets/…`), ולכן הוא עובד גם בשורש של דומיין וגם בתת-תיקייה — בלי שינוי.

## פתוח / להחלטה

- **המספרים בעמוד הם מהספרים האמיתיים** (8.68M ₪, 287 חשבוניות, שפיר/מגידש/נוימן בשמם).
  זה מה שנותן לעמוד אמינות, אבל צריך החלטה מה מהם ציבורי.
- שמות ספקים במסך הדוגמה — להחליף באנונימיים אם העמוד יוצא החוצה.
- אין עדיין: עמוד מוצר, למי זה, תמחור, אודות, צור קשר, טופס ליד.
- מתחת ל-860px קישורי הניווט מוסתרים ואין תפריט המבורגר — רק הלוגו וה-CTA. נדרש לפני עלייה.
- ה-CTA מצביע על `#` — אין עדיין יעד (טופס / קביעת פגישה).

## הערות מימוש שכדאי לדעת

- **בידי (RTL).** מחרוזת אחת שמערבבת מספר ויחידה בעברית (`"8,463 ק״ג · 27,082 ₪"`)
  מסודרת מחדש ע״י אלגוריתם הבידי ויוצאת משובשת. הדפוס בעמוד: **המספר לבד בתוך `.num`,
  היחידה בעברית מחוץ לו.** אותו דבר ב-JS (`n()` ב-`app.js`) וב-HTML.
  הנוסחה במחשבון מוצגת ביחידות לטיניות (`kg/m²/mm`) מאותה סיבה.
- `.bar__fill` ו-`.minibar i` הם `<i>` וחייבים `display:block` — רוחב וגובה לא חלים על inline.
- הניווט הוא `sticky` ולא `fixed`, כדי שיישב אחרי באנר הסקיצה ולא עליו.
